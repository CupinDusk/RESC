## Independent exactness argument

Partition increasing slots into singleton blocks and reversed adjacent pairs. The complete ranking preserves block order and reverses order only inside the size-two blocks. Thus its only allowed leftward edges are `b -> a` inside a reversed adjacent pair `a,b`.

Take any disjoint source/target sets of equal size with an allowed bijection. On a line, an assignment's distance cost is the sum over slot gaps of gap length times the number of matching edges crossing the gap. The free optimum is the sum of gap length times the absolute difference between source and target prefix counts. A matching reaches that optimum exactly when no gap is crossed in both directions.

If an allowed matching crosses some gap both ways, its leftward edge is a reversed adjacent pair `b -> a`. The rightward edge must be `p -> q` with `p<a<b<q`: the source and target sets are disjoint and all matching endpoints are distinct. Both replacement edges `p -> a` and `b -> q` are allowed because they join earlier to later blocks. Swapping these two targets decreases cost by `2*(j_b-j_a)>0`. Consequently a minimum allowed matching has no opposite crossing, attains the free lower bound, and has cost ratio one. This proves `C_R=1` for all disjoint-endpoint assignments admitted by every one of the 15 declared rankings, including arbitrary strictly increasing slot geometry. The nonempty free costs are positive because endpoint sets are disjoint.

The independent checker did not call the author's quartet function. It enumerated all six directed two-source/two-target cuts of every four-slot set, explicitly enumerated both bijections, and compared the best allowed cost with the unrestricted cost. All **12,118,086** directed quartet cuts across 15 rankings passed. For every ranking with `n=4` or `n=8`, it additionally enumerated every equal-size disjoint source/target pair and all target permutations, rather than relying on quartets. Per family, `n=4` covered 18 endpoint pairs and 24 bijections; `n=8` covered 1,106 endpoint pairs and 5,936 bijections. There were 8 and 322 admitted endpoint pairs respectively, all at ratio one. Full assignment enumeration was not attempted for `n>=16`; the argument above covers all sizes and the independent quartet enumeration covers every prescribed ranking.

## Actual complete-job boundary

Every timed repeat constructs a fresh route-specific Plan, copies positions/edges, and performs that route's closure/classifier preparation. The destructor is within the returning complete job. Raw performs raw graph BF. Closed computes closure and performs closure graph BF; despite a stale generic core comment calling route 1 “beta,” `complete_job` intentionally passes zero as the query route for both Raw and Closed, identically to R04. Cheap performs closure, the unchanged Cheap recognizer, beta/span scanning and fallback graph BF. Quartet additionally performs the general quartet scan, then beta scanning and exact admission without a graph. It does not use the specialized adjacent-reversal flag.

All 48 rectangle arrays, query sequences, schedules and reusable Scratch capacity are preloaded. The full untimed warmup touches every route, stratum and Q. Consequently graph-buffer capacity allocation is amortized/preloaded rather than charged anew to every query; graph weights and BF vectors are still constructed/reset during each fallback. Route-specific Plan construction/allocation is timed. These are preparation-inclusive jobs over preloaded inputs and common reusable scratch, not cold process startup or input parsing jobs.

The `asm volatile` input pointer with a memory clobber prevents hoisting route work across repeated calls. Each returned Boolean contributes to a timed rolling hash; jobs contribute to `h`, which is checked and added to volatile checksum after the end timestamp. Assembly confirms the complete jobs and hash loop survive optimization. Expected-check work, the outer volatile update, parsing, validation and CSV/log output are equally outside the timed interval; the rolling decision hash is inside. Correctness/certificate validation is untimed and no certificate-service cost is claimed.

Graph expressions cast bounds and delta products to signed 128-bit before relevant arithmetic. The largest absolute reconstructed graph edge is 4,728; even `64^3*4728` is about 1.24e9, far below the signed-128 domain. Actual int64 slot differences, quartet sums, span arithmetic, and int hash payloads are also safely bounded. Hash addition/multiplication intentionally wrap unsigned 64-bit. There is no floating log calculation or outward-rounded physical enclosure in this study.

## Failures, warning and disposition

No producer correctness or replacement bug was found. The census compile emits `-Wsometimes-uninitialized` for `b` after `require(query(...,&a) && query(...,&b), ...)`: if the first operand is false, `require` exits through `[[noreturn]] fail` before the subsequent read. On this all-admit corpus both operands execute. This warning is a readability/diagnostic limitation, not an executed or reachable undefined read; the original source remains preserved.

Auditor execution errors are recorded rather than disguised as clean first passes: (1) an incorrect working-directory assumption created an empty nested output tree and a failed build; the exact empty tree was checked and removed, (2) another wrong relative-path command failed census compilation/input copies and validation reported inputs missing, (3) the first checker assumed LF whereas Windows `Path.write_text` produced CRLF, and (4) initial PE normalization omitted two timestamp copies in `.buildid`. The latter failed result is preserved and the final checker documents all corrections. None required modifying producer evidence or recollecting timings.

The final audit is PASS for the declared synthetic CPU routing scope, subject to the limitations above. This audit supplies no GPU, native application, physical-device, outward-log, cryptographic-certificate or conference-acceptance claim.
