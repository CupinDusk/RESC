The mathematical fixtures are controlled constructions, not device observations.

For distinct arms p/q let u_pq=log(Up/Lq), a_pq=log(Lp/Uq). Self contrasts are exactly zero in every alternative. The anchored flexible path has b0=0, adjacent differences at most delta in magnitude. Its position-wise marginal is [-j*delta,j*delta]. The independent-marginal model keeps exactly these ranges and discards only the joint path constraint. The linear model b_j=alpha*j, |alpha|<=delta is a subset of the flexible path.

Endpoint support and telescoping give shared-path support u_pq+delta*|jp-jq|. A linear slope attains the same bound, so ALL pair supports, fixed-choice worst regrets and guaranteed minimizers agree between linear/path for any intervals/budget. The marginal relaxation instead has support u_pq+delta*(jp+jq). Worst log regret is the finite maximum of distinct supports and zero. This is established robust-regret reasoning specialized to these sets, not a new general optimization principle.

Possible winners require one jointly feasible scenario. A path candidate p is possible iff a_pq<=delta*|jp-jq| for every rival: choose xp=log Lp, rivals at log Uq, and one cone b_j=-delta*|j-jp| shifted to anchor0. The independent box uses candidate b at its positive endpoint and every rival at its negative endpoint. The linear set requires one common slope satisfying every a_pq<=alpha*(jp-jq), an interval-intersection test. Pairwise feasibility alone is insufficient for this smaller correlated set.
